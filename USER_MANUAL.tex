\section{Overview}

The Survey Workbench is a robust desktop application designed to streamline participant folder generation and automate questionnaire data extraction from fillable PDF forms into centralized CSV or Excel masterfiles. Version 2.2 features a streamlined interface with a collapsible configuration container, dynamic window resizing, and robust configuration management.

\subsection{Key Features}
\begin{itemize}
    \item Collapsible Configuration container (hidden by default for cleaner end-user presentation)
    \item Dynamic window resizing that adapts automatically to presented content
    \item Dynamic questionnaire configuration supporting unlimited custom survey types
    \item Batch processing capabilities for generating folders and extracting data across multiple participants simultaneously
    \item Participant list import functionality supporting text and CSV formats
    \item Configuration snapshotting for saving and reloading complete study setups, folder paths, and parameters
    \item Automated duplicate detection against masterfiles (CSV, XLS, XLSX)
    \item Data completeness verification and missing data reporting
    \item Interactive help system featuring tooltips and a dedicated ``What's This?'' mode
    \item Automated format detection for masterfiles with interactive preview dialogs prior to committing data
\end{itemize}

\subsection{System Requirements}
\begin{itemize}
    \item Windows 10/11 or Linux operating systems
    \item Microsoft Excel (required for Excel masterfile readout via xlwings on Windows)
    \item Python 3.x environment with PyQt5 and pypdf dependencies (or deployed as a standalone compiled binary)
\end{itemize}

\section{Getting Started and Interactive Help}

When you first launch Survey Workbench v2.2, you will see a clean, focused window containing:
\begin{enumerate}
    \item \textbf{Participant Declaration} -- For entering single or multiple participant IDs.
    \item \textbf{Configuration Settings} -- A collapsible dropdown container (collapsed by default) for advanced setup.
    \item \textbf{Action Buttons} -- Always visible buttons to generate participant folders or extract data immediately.
\end{enumerate}

If you are ever unsure what a specific control does:
\begin{itemize}
    \item \textbf{Tooltips}: Hover your mouse over any control to see a brief description of its function.
    \item \textbf{What's This? Mode}: Navigate to \textbf{HELP $\rightarrow$ What's This? (Click for Help)} or press \textbf{Shift+F1}. Your cursor will change into a question mark; click on any interface element to open a detailed explanatory window outlining its exact purpose and usage.
\end{itemize}

\section{Configuration Settings}

For study curators, click the \textbf{▶ Configuration Settings} toggle button to reveal the configuration panels. The window will dynamically expand to fit the settings.

\subsection{Target and Source Paths}
\begin{itemize}
    \item \textbf{Target folder PATH}: Choose where participant folders will be created during generation.
    \item \textbf{Source folder PATH}: Choose the folder containing completed participant data folders.
    \item \textbf{Masterfile PATH}: Choose your masterfile (.csv, .xls, or .xlsx) for data readout.
\end{itemize}

\subsection{Configuring Questionnaire Types}
\begin{enumerate}
    \item Enter the number of different questionnaire types in \textbf{Number of questionnaire types}.
    \item Click \textbf{Confirm} to generate the scrollable configuration rows.
    \item For each row, specify the \textbf{Survey Name}, select the PDF template via \textbf{Search}, and set the \textbf{Number of copies}.
\end{enumerate}

\section{Step-by-Step Guide: Generating Participant Folders}

\subsection{1. Declaring Participant IDs}
\begin{itemize}
    \item \textbf{Single Mode}: Enter a unique identifier directly into the \textbf{Participant ID} text box (e.g., \texttt{P001}). This will be used as the subfolder name.
    \item \textbf{Batch Mode}: Check \textbf{Batch Mode (multiple IDs)} to open a text area where you can input multiple participant identifiers (one per line or comma-separated). Alternatively, click \textbf{Import List...} to load IDs directly from an external text or CSV file.
\end{itemize}

\subsection{2. Generating Folders}
Click \textbf{Generate Participant Folder(s)}. Even when the configuration settings are collapsed, the system uses your active configuration in the background to create subfolders for each participant ID inside the target folder, copy and rename questionnaire templates according to your specifications, and open the consolidated prefill dialog to review and edit form data before final output.

\section{Step-by-Step Guide: Extracting Data to Masterfiles}

With the participant ID(s) declared and source/masterfile paths configured, click \textbf{Extract Data to Masterfile}. 

\subsection{Batch and Single Extraction}
\begin{itemize}
    \item For single participants, a 4-column preview dialog lets you inspect and edit field mapping names and extracted data values prior to commit.
    \item For multiple participants or batch mode, data is processed across all specified participants in a single consolidated session, writing directly into dedicated sheets per root PDF in Excel or appending rows to CSV masterfiles.
    \item Column A in Excel sheets is automatically designated as \texttt{participant\_id}.
\end{itemize}

\subsection{Quality Control: Completeness and Duplicates}
Before running extraction, the software incorporates built-in safety checks:
\begin{itemize}
    \item \textbf{Duplicate Detection}: Automatically scans the masterfile to check if a participant ID has already been extracted, preventing accidental duplicate entries.
    \item \textbf{Data Completeness}: Verifies that all expected readable PDF form fields and data files are present. You can also click \textbf{Missing Data Report} to scan the entire source directory and generate a comprehensive summary of complete versus incomplete participant folders.
\end{itemize}

\subsection{Field Mapping}
Access \textbf{File $\rightarrow$ Save/Edit Field Mapping} from the menu bar to map technical PDF form field identifiers to user-friendly column headers. Mappings are automatically saved into your active configuration snapshot.

\section{Configuration Management}

Save and load complete snapshots of your study setup—including folder paths, questionnaire parameters, and custom field mappings—using \textbf{File $\rightarrow$ Save Configuration} and \textbf{File $\rightarrow$ Load Configuration}. Saved configurations can be easily reloaded or deleted using the respective submenus under the \textbf{File} menu.

\section{Technical Information and Version History}

\subsection{Complete Version History}
\begin{itemize}
    \item \textbf{v2.2 (Current Edition)}: Introduced collapsible curator configuration containers, dynamic window resizing, comprehensive PDF form field extraction via AcroForm and widget annotation scanning, interactive prefill and extraction preview dialogs, robust batch processing with list imports, automated duplicate checking, missing data reporting, and flexible configuration snapshotting.
    \item \textbf{v2.1}: Added structured field mapping capabilities, enhanced masterfile format auto-detection, and refined prefill preset handling.
    \item \textbf{v2.0}: Established dynamic questionnaire configuration supporting unlimited questionnaire types and unified masterfile readout for CSV and Excel formats.
    \item \textbf{v1.0 (Initial Release)}: Basic static folder generation and single-format CSV data extraction for fixed questionnaire types (Demographics and NASA-TLX).
\end{itemize}

\subsection{Technology Stack and Deployment}
\begin{itemize}
    \item Python 3.x
    \item PyQt5 (GUI framework featuring tooltips and What's This interactive help)
    \item xlwings (Excel integration and workbook automation)
    \item pypdf (PDF form field reading and writing)
    \item Nuitka (Cross-platform compiler used to compile the source code into native standalone executables, generating `.exe` binaries on Windows and ELF binaries on Linux)
\end{itemize}
